## Дизайн и качество

- [Исходная визуальная концепция](design-reference.webp) — исторический ориентир, созданный перед версткой; в готовом сайте есть последующие правки.
- [Правки по аудиту Hallmark](hallmark-polish.md) — что улучшено и как проверено на момент полировки. Счётчики анализатора относятся к той проверке, а не к каждому последующему коммиту.

Дизайн развивался с помощью `ui-design` и `awwwards-ui-skills`, затем прошёл аудит Hallmark. Выбранный референс определил тёмную палитру, антиквенные заголовки, композицию фотографий и отсутствие декоративных стрелок и нумерации.

Практические инструкции — в [руководстве для разработки](../CONTRIBUTING.md). Обзор сайта — в [главном README](../README.md).
