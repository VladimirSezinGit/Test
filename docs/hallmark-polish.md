# Правки после аудита Hallmark

Внесена точечная полировка согласованного тёмного макета.

## Исправления

- **Читаемость.** Метаданные подвала, ссылка конфиденциальности и примечание об AI-визуализациях теперь набраны размером не менее 12 px. Ссылки навигации на телефоне — 14 px. Подвал и его навигация поддерживают переносы.
- **Нажатие.** Основные кнопки, фильтры, меню, закрытие диалогов, карточки проектов и текстовые действия получили `:active`. Меняется цвет, анимация и сдвиг верстки не добавляются. Фокус и отключённое состояние сохранены.
- **Токены.** Цвета hover, выделения, градиентов, рамок, подсказок и скроллбара перенесены в `:root` с семантическими именами. Палитра выбранного макета сохранена; отдельные токены добавлены для состояния нажатия.
- **Сетки.** Долевые колонки используют `minmax(0, ...)`, содержимое сеток может сжиматься, заголовки получили `min-width: 0` и `overflow-wrap: break-word`.

Основная реализация находится в [styles.css](../styles.css). Актуальные снимки: [десктоп](preview.jpg), [телефон](mobile.jpg).

## Проверка

- `npm run check` — успешно.
- `npm test` — оба теста прошли.
- `npm run build` — успешно.
- `python scripts/browser-check.py` — прошли фильтры, три проекта, мобильная галерея, меню, диалоги, FAQ, клавиатурное управление, валидация и скачивание брифа.
- Дополнительно проверены ширины 320, 375, 390, 414, 768, 1024, 1280, 1440 и 1920 px: текст подвала не меньше 12 px, горизонтального переполнения страницы нет.
- Нажатие основной кнопки проверено настоящим `mouse.down`: заливка меняется, размеры и положение кнопки остаются прежними.
- Повторно выполнены статический и браузерный анализаторы Hallmark. Срабатывания по токенам цвета (48), защите сеток (50), мелкому видимому тексту (75) и отсутствию `:active` (26b) устранены.

Полное прохождение всех стилевых правил Hallmark не заявляется: оставшиеся замечания включают ранее разобранные правила о тире, разделителях, служебной метке, подписях перед заголовками, плотном интерлиньяже, карточках-кнопках и доле фотографий. В аудит также попадает блокировка фоновой прокрутки при открытом диалоге; её поведение проверено.

Выбранные пользователем композиция, фотографии, тексты, межстрочные интервалы крупных заголовков и существующая логика сохранены. Скрипты сайта и тестов не изменялись для получения положительного результата.
