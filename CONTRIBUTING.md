# Разработка и проверка

## Подготовка

Нужен Node.js 22 или новее. Если используете nvm, выполните `nvm use` в корне проекта. Основная ветка репозитория — `main`.

```sh
npm run dev
```

Сервер доступен по адресу `http://localhost:3000`. Для другого порта в Bash: `PORT=8080 npm run dev`. Остановка — `Ctrl+C`.

## Где менять сайт

- Тексты, секции и поля формы — `index.html`.
- Цвета и стили — `styles.css`. Цвета задаются семантическими переменными в `:root`.
- Описания проектов и интерактивность — `app.js`.
- Изображения и шрифты — `assets/`. Учитывайте подписи `alt`, размеры и лицензии.

Проект не требует сборщика или сторонних библиотек для работы в браузере. Не добавляйте зависимости без необходимости.

## Перед отправкой изменений

```sh
npm run check
npm test
npm run build
```

После изменений интерфейса проверьте десктопную и мобильную верстку, клавиатурную навигацию и видимый фокус. Тексты в подвале и важные примечания должны оставаться читаемыми. Кнопки и поля не должны менять размеры при нажатии или фокусе.

## Проверки в браузере

Playwright используется только для разработки. Запустите сервер в отдельном терминале, затем выполните:

```sh
python -m pip install playwright
python -m playwright install chromium
python scripts/browser-check.py
```

Если Chromium уже установлен, скрипт использует его автоматически. При необходимости путь можно передать через переменную `CHROMIUM_PATH`.

Для проверки готовой сборки запустите `npm run preview` и укажите её адрес:

```sh
python scripts/browser-check.py --url http://localhost:3000
```

Скрипт проверяет адаптивность, три проекта, фильтры, мобильную галерею, меню, диалоги, возврат фокуса, валидацию и содержимое скачанного брифа. Автоматические браузерные проверки в GitHub Actions не включены.

## Документация и изображения

После заметного изменения интерфейса обновляйте:

- `docs/cover.jpg` — первый экран на компьютере;
- `docs/preview.jpg` — десктопную страницу целиком;
- `docs/mobile.jpg` — мобильную страницу целиком.

Убирайте фокус и временные состояния перед снимком; дождитесь загрузки локальных шрифтов и изображений. Исходная дизайн-концепция в `docs/design-reference.webp` хранится как исторический ориентир и может отличаться от готовой страницы.

Лицензии MIT и SIL Open Font License сохранены на языке оригинала. Реальные ключи, персональные данные и учётные данные в репозиторий не добавляются.
