# ТИШЕ — студия интерьерной архитектуры

Адаптивный сайт-портфолио: тёмная палитра, выразительная типографика и интерьерные проекты. Реализован на HTML, CSS и JavaScript без внешних зависимостей для работы сайта.

## Что умеет сайт

- Адаптируется под компьютеры, планшеты и телефоны.
- Показывает три проекта с фильтрами и подробностями в диалоговых окнах.
- Поддерживает горизонтальную галерею на телефоне, мобильное меню и навигацию с клавиатуры.
- Раскрывает подход студии, этапы работы и ответы на частые вопросы.
- Помогает составить бриф и скачать его текстовым файлом.

Интерфейс использует локальные шрифты **Cormorant Garamond** и **Inter**, изображения в WebP и собственную палитру CSS-переменных. Диалоги возвращают фокус после закрытия, поля имеют подписи, а нажатия кнопок получают визуальное подтверждение.

## Быстрый запуск

Требуется **Node.js 22 или новее**. Запустите из корня репозитория:

```sh
npm run dev
```

Откройте `http://localhost:3000`. Устанавливать пакеты для запуска не требуется. Для другого порта в Bash: `PORT=8080 npm run dev`.

## Команды проекта

| Команда           | Назначение                                    |
| ----------------- | --------------------------------------------- |
| `npm run dev`     | Локальный сервер разработки                   |
| `npm run check`   | Проверка синтаксиса JavaScript                |
| `npm test`        | Проверка ресурсов, якорей и HTTP              |
| `npm run build`   | Сборка статического сайта в `dist/`           |
| `npm run preview` | Просмотр готовой сборки после `npm run build` |

Проверки синтаксиса, тесты и сборка выполняются в GitHub Actions. Инструкции по браузерным проверкам и работе с кодом находятся в [руководстве для разработки](CONTRIBUTING.md).

## Структура

```text
index.html       Содержимое страницы, форма и диалоги
styles.css       Палитра, типографика и адаптивная верстка
app.js           Меню, фильтры, диалоги и скачивание брифа
assets/          Изображения, шрифты, значок и лицензии шрифтов
docs/            Скриншоты, дизайн-концепция и результаты полировки
scripts/         Сервер разработки, сборка и проверки
.github/         Автоматические проверки GitHub Actions
```

## Публикация

```sh
npm run build
```

Разместите содержимое `dist/` на статическом хостинге. Например, для Cloudflare Pages или Netlify задайте команду сборки `npm run build` и выходной каталог `dist`. Относительные пути позволяют разместить сайт в подпапке.

Автоматическая публикация сайта не настроена. После выбора домена укажите абсолютный адрес `og:image` и добавьте `og:url` в `index.html`.

## О демонстрации

**ТИШЕ — вымышленная студия, а проекты — концепции с AI-визуализациями.** Сайт создан для портфолио и не предлагает реальные коммерческие услуги.

Бриф обрабатывается в браузере и скачивается на устройство. **Форма не отправляет заявку и не сохраняет данные на сервере.** Аналитика, рекламные трекеры и cookies не используются. Для реального приёма обращений потребуется отдельная серверная интеграция.
